# Old Feints Generation 1

These files are archived references for the first generation of hand-written
combat feints.

They are intentionally outside `src/` and are not imported by the active combat
catalog. Use them only as design references while building the next feint set.

Archived files:

- `tactical.py` - old basic tactical feints.
- `dirty.py` - old dirty-trick feints.
- `weapon_moves.py` - old weapon move feints.
