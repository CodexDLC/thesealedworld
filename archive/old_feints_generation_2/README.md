# Old Feints Generation 2

These files are archived references for the second generation of systematic
combat feints.

They are intentionally outside `src/` and are not imported by the active combat
catalog. Use them only as design references while building the new feint set.

Archived files:

- `tactical_techniques.py` - old skill/tag-based tactical techniques.
- `weapon_techniques.py` - old tiered weapon techniques.
