# 🧠 Тактический слой и Экономика токенов (Tactical Layer & Tokens)

## 1. Концепция интерфейса: "Target-Centric UI"
Боевой интерфейс полностью подчинен текущей цели. Это исключает лишний шум и фокусирует игрока на конкретной дуэли.

*   **Ожидание (Waiting):** Если активной цели нет, кнопки атак скрыты. Доступны только системные действия («Сбежать», «Обновить»).
*   **Контакт (Active):** При появлении цели разворачивается «Боевая панель». Все возможности на ней привязаны именно к этому противнику.

## 2. Семерка путей Тактики
Тактические токены — это валюта мастерства. Они отражают, как именно персонаж ведет себя в бою.

### 🎯 Меткость (Hit)
*   **Как получить:** Атакующему за факт физического контакта (удар не промахнулся и враг не увернулся). Даже если нанесен 0 урона, контакт засчитан.

### ⚔️ Превосходство (Mastery)
*   **Как получить:** Атакующему за «критический момент» (идеальное выполнение приема). Это показатель чистого мастерства.

### 🌑 Тень (Shadow)
*   **Как получить:** Защитнику за успешное уклонение (Dodge) от вражеской атаки.

### 🛡️ Сталь (Steel)
*   **Как получить:** Защитнику за успешное парирование (Parry) удара основным оружием.

### 🧱 Щит (Bulwark)
*   **Как получить:** Защитнику за успешный блок (Block) удара щитом.

### ⚡ Ответ (Riposte)
*   **Как получить:** Атакующему за успешно проведенную контратаку после защиты.

### ⏳ Темп (Tempo)
*   **Как получить:** Защитнику, если атакующий провалил проверку Меткости (промахнулся).
*   **Смысл:** Защитник использует «криворукость» и инерцию промаха врага, чтобы перехватить ритм боя и подготовить свой выпад.

## 3. Экономика Дара (Gift)
Дар — это пассивный ресурс потенциала Симбионта.

*   **Начисление:** +1 токен Дара получают оба участника за каждый совершенный размен ударами (Exchange).
*   **Смысл:** Это «гарантированное» топливо для мощных способностей, которое копится само по себе в пылу сражения.

## 4. Боевое чутье (Фокус)
Персонаж действует на рефлексах, а игрок лишь подтверждает его намерения.

*   **Поле возможностей:** Список всех финтов, на которые хватает токенов.
*   **Фокус:** Конкретные 3-4 приема, которые «Боевое чутье» вывело на экран прямо сейчас.

При появлении варианта система депонирует (бронирует) под него токены. Ресурс считается вложенным в этот замах.

Если игрок выбирает базовую атаку — подготовленный финт остается «в руке», пока не будет реализован.
