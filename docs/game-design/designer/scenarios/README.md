# 📜 Домен: Сценарии и Сюжет (Scenarios Domain)

Этот раздел содержит дизайн-документы конкретных квестов, сюжетных арок и событий. Здесь описывается не *как* работает движок (см. World Domain), а *что* именно происходит с игроком.

> **Implementation Note:** JSON-конфигурации сценариев находятся в `apps/game_core/resources/scenarios/json/`.

---

## 📖 Содержание домена

### 1. [Нулевой Осколок (Zero Shard / Awakening)](./01_zero_shard.md)
**О чем:** Туториал. Скрытая калибровка персонажа через выборы. Материализация стартового билда.

---

## 🎯 Основная цель домена
Создать захватывающие истории, где выборы игрока имеют реальные последствия для его характеристик и мира.
