# Gifts Domain

This section is the current design source for Gifts and the Symbiote energy
progression branch.

Gifts are not classic magic. They are energy constructs connected to the
Symbiote, rifts, and the player's energy profile. In gameplay terms, Gifts will
be expressed through active abilities, passive abilities, combat modifiers,
triggers, conflicts, and build combinations.

This is design-source material, not implementation documentation. Current code
and stable runtime behavior remain documented under `docs/ru`.

## Core Principles

- Skills represent trained mastery: weapon use, tactics, crafting, survival,
  social expertise, and other learned capabilities.
- Gifts represent the energy branch: Symbiote power, rift energy, school
  affinity, and supernatural or enhanced physical capabilities.
- A Gift does not have to be a spell. It can strengthen physical attacks,
  defense, mobility, recovery, control, or weapon behavior.
- The first Gifts are discovered through player behavior and affinity analysis.
- Later progression should allow replacement, recombination, and build changes.
- Gift combat uses both Energy and Gift tokens.
- Gift and Symbiote rank use an 8-step scale from `0` to `7`.
