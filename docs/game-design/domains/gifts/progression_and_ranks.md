# Progression And Ranks

Gift and Symbiote progression use a separate path from normal skills.

The Symbiote has one main progression scale based on experience. This experience
should not be treated as generic monster-kill XP. It should come from meaningful
actions: rift activity, energy absorption, Symbiote events, and other actions
that require player intent rather than passive farming.

Skills grow through practice. Gifts grow through Symbiote development, rift
energy, special resources, and future energy events.

Early in the game, the player may see only system messages and unexplained
energy feedback. The Symbiote should not be fully known as a separate entity
until the first awakening path reaches level 2.

At Symbiote level 2, a naming quest reveals the Symbiote and opens the first
conscious Gift. This is the narrative and mechanical transition from hidden
system feedback to deliberate energy control.

## Rank Scale

Gifts use an 8-step rank scale:

| Rank | Meaning |
| --- | --- |
| `0` | Dormant, unformed, or barely awakened. |
| `1` | First usable expression. |
| `2` | Stable beginner expression. |
| `3` | Developed expression. |
| `4` | Strong expression. |
| `5` | Advanced expression. |
| `6` | Near-complete expression. |
| `7` | Absolute expression. |

The rank names are placeholders. Final naming should use project-specific
terminology instead of generic RPG rarity terms.

## Symbiote Rank

The Gift rank is closely related to Symbiote rank. The exact relationship is not
finalized, but the working idea is:

- the Symbiote defines the owner's maximum or effective Gift strength;
- higher Symbiote rank improves offensive and defensive Gift performance;
- rank can multiply, unlock, or reshape ability effects;
- rank can influence token generation, Energy efficiency, or passive strength.
- Symbiote level 2 is the current design point for the first named awakening
  and first conscious Gift choice.

## Progression Sources

Symbiote and Gift progression should come from energy-specific or
intent-driven activity:

- closing rifts;
- absorbing or accumulating rift energy;
- spending rare energy resources;
- completing Symbiote events;
- meaningful actions that cannot be reduced to unattended farming;
- future Gift-specific trials;
- future high-risk world content.

The Gift branch should not progress only because the player repeatedly uses a
normal weapon or craft action. That behavior belongs to skills.
