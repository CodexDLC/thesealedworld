# Gift Schools Specification (RBC v3.1)

## 1. Концепция Школ
В игре существует 8 основных школ (типов энергии), доступных для управления через Симбиота.

| Школа | Название | Описание |
| :--- | :--- | :--- |
| **fire** | 🔥 Пирокинез | Огонь, взрывы, агрессия. |
| **water** | 💧 Гидрокинез | Вода, яды, лечение, контроль потоков. |
| **air** | 🌪️ Аэрокинез | Воздух, молнии, скорость, невидимость. |
| **earth** | 🪨 Геокинез | Земля, камень, защита, физическая мощь. |
| **light** | ✨ Люминис | Свет, барьеры, выжигание скверны. |
| **darkness** | 🌑 Умбра | Тьма, тени, вампиризм, ослабление. |
| **arcane** | 🔮 Аркана | Чистая энергия, манипуляция реальностью. |
| **nature** | 🌿 Вита | Природа, жизнь, призыв зверей, шипы. |

---

## 2. Механика Способностей
Каждый Дар предоставляет набор способностей (Active Abilities).

*   **Ресурс:** Способности тратят **Энергию** (Energy) и **Токены Дара** (Gift Tokens).
*   **Накопление:** Токены Дара копятся каждый боевой размен (автоматически или за действия).
*   **Применение:** Игрок тратит накопленные токены на мощные заклинания.

> **Note:** Конкретные способности и формулы будут разработаны позже. Текущий список в коде — нарративный референс.
