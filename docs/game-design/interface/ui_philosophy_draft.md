# 🖥️ Философия UI: Dual-Message System (Draft)

Опыт интерфейса строится на разделении потоков информации.

## Dual-Message System
Игрок всегда видит два сообщения:

1.  **Верхнее (Menu):** Постоянный статус, био персонажа, в бою — лог событий. Это "приборная панель", которая всегда перед глазами.
2.  **Нижнее (Content):** Активная рабочая область. Текст сцены, выбор действий, карточка предмета. Здесь происходит взаимодействие.
