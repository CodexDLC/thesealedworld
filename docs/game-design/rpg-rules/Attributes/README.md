# 📂 Attributes Rules

[⬅️ Назад: RPG Rules](../README.md)

## 🎯 Описание
Полная спецификация 9 базовых атрибутов: их философия, роль в системе и математическое влияние на характеристики.

---

## 1. Body Node (The Vessel)
**Логика Симбиота:** Управление биомеханикой и физиологией. Симбиот снимает биологические ограничители и укрепляет структуру.

### Strength (Сила)
**Code Name:** `strength`
**Суть:** Симбиот отключает предохранители мышц, заставляя их сокращаться с пиковой мощностью. Это "гидравлика" организма.

*   **Base Damage (Базовый Урон):**
    *   Дает **1-2 ед.** урона за очко.
    *   Работает как для Unarmed, так и как бонус к оружию.
*   **Physical Penetration (Физ. Пробивание):**
    *   Дает **2%** пробивания за очко.
    *   Снижает эффективность чужого Физ. Резиста.
    *   **Bleed Efficiency:** Определяет глубину раны и эффективность кровотечения.
*   **Carry Weight:** Грузоподъемность.

### Agility (Ловкость)
**Code Name:** `agility`
**Суть:** Симбиот контролирует прохождение нервных импульсов. Это идеальная координация, баланс и мгновенная реакция (Ping 0ms).

*   **Dodge Chance (Уклонение):**
    *   Дает **+5%** к рейтингу уклонения за каждое очко.
*   **Initiative (Инициатива):** Скорость реакции тела в бою.
*   **XP Factor:** Основной множитель для прокачки навыков реакции (Parrying).

### Endurance (Выносливость)
**Code Name:** `endurance`
**Суть:** Симбиот уплотняет кожу, кости и изменяет метаболизм. Тело превращается в защищенный скафандр.

*   **Max HP (Здоровье):**
    *   Считается от среднего Body node: `(strength + agility + endurance) / 3 * 4`.
*   **HP Regen (Регенерация):**
    *   Считается от среднего Body node: `(strength + agility + endurance) / 3 * 0.1`.
    *   Базовая скорость восстановления тканей.
*   **Physical Resistance (Физ. Резист):**
    *   Дает **2%** резиста за очко.
    *   Сопротивление структуры тела (работает после брони).
*   **Bio-Resistances (Био-защита):**
    *   Дает **2%** резиста за очко.
    *   Включает: **Poison** (Яд), **Bleed** (Кровотечение), **Environment** (Среда).

## 2. Core Node (The Core)
**Логика Симбиота:** Управление Энергией. Симбиот строит Энергетические Конструкты (заклинания) и держит буфер данных.

### Intellect (Интеллект)
**Code Name:** `intellect`
**Суть:** Вычислительная мощность (CPU). Способность мгновенно рассчитывать сложнейшие 3D-матрицы Энергетических Конструктов.

*   **Spell Base Damage (Маг. Урон):**
    *   Дает **1-2 ед.** урона за очко.
*   **Magic Penetration (Маг. Пробивание):**
    *   Дает **2%** пробивания за очко.
    *   Способность "взломать" чужую ауру.
*   **Tactics Driver:** Вместе с Памятью отвечает за навык **Tactics**.

### Memory (Память)
**Code Name:** `memory`
**Суть:** Емкость системы (RAM). Симбиот использует нейроны как резервуар данных.

*   **XP Gain (Скорость Адаптации):** Глобальный множитель опыта.
*   **Active Constructs Limit:** Лимит активных заклинаний/способностей (Memory Slots).
*   **Counter-Attack Base:** Дает основной прирост к базовому шансу контратаки (~0.25% за очко). Вы помните паттерны врага.
*   **Tactics Driver:** Вместе с Интеллектом отвечает за навык **Tactics**.

### Mental (Ментальность)
**Code Name:** `mental`
**Суть:** Стабильность и защита ядра (Firewall). Изоляция нервной системы от перегрева энергией и внешних атак.

*   **Energy / Mana Pool:**
    *   Считается от среднего Core node: `(intellect + memory + mental) / 3 * 2`.
*   **Energy Regen (Регенерация):**
    *   Считается от среднего Core node: `(intellect + memory + mental) / 3 * 0.5`.
    *   Скорость восстановления ментального ресурса.
*   **Energy-Resistances (Энерго-защита):**
    *   Дает **2%** резиста за очко.
    *   Включает: **Magic** (Магия), **Elemental** (Стихии).
*   **Control-Resistances (Анти-Контроль):**
    *   Дает **2%** резиста за очко.
    *   Включает: **Control** (Stun/Root), **Mental** (Fear/Sleep).

## 3. Sensor Node (The Interface)
**Логика Симбиота:** Обработка Входящих данных (Input) и Проекция Исходящих (Output).

### Perception (Восприятие)
**Code Name:** `perception`
**Суть:** Обработка входящего потока (Scanner). Симбиот маркирует цели, подсвечивает траектории и лут.

*   **Anti-Evasion (Трейсинг):**
    *   Дает **+3%** к Анти-Увороту за каждое очко.
*   **Critical Accuracy:** Если Анти-Уворот превышает Уворот цели в 2 раза -> гарантированный мини-крит.
*   **Detection:** Дальность сенсоров и поиск скрытого лута.

### Projection (Проекция)
**Code Name:** `projection`
**Суть:** Активная трансляция сигналов вовне (Projector). Симбиот создает голограммы или давит на мозг окружающих.

*   **Social Influence:** Торговля и убеждение через ментальное давление.
*   **Debuff Efficiency (Poison):** Шанс наложить яд (Land Chance). Пробитие ментальной/био защиты врага.
*   **Illusions:** Смена внешности и маскировка.

### Prediction (Предвидение)
**Code Name:** `prediction`
**Суть:** Модуль предиктивного анализа (Analyzer). Симбиот просчитывает физику мира на секунду вперед.

*   **Counter-Attack Base:** Дает дополнительный прирост к базовому шансу контратаки (~0.15% за очко). Вы предугадываете момент.
*   **Concentration Timing:** Вместе с Восприятием и Проекцией увеличивает запас и восстановление концентрации.
    *   Максимум: `(perception + projection + prediction) / 3 * 10`.
    *   Восстановление: `1 + (perception + projection + prediction) / 3 * 0.3`.
*   **Crafting Quality:** Идеальный тайминг при создании предметов.
*   **Loot Luck:** Влияет на удачу в поиске редких предметов (Find Loot Chance).
