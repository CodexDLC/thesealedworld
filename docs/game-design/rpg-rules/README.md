# 📂 RPG Rules (Stateless Engine)

[⬅️ Назад: Core Layer](../README.md)

## 🎯 Описание
"Физика мира". Правила, по которым работают статы и скиллы.

## 🗺️ Структура
* [**Attributes/**](./Attributes/README.md) — Сила, Ловкость и их влияние.
* [**Skills/**](./Skills/README.md) — Дерево навыков и прогрессия.
* [**Abilities/**](./Abilities/README.md) — Спецификация активных способностей.
* [**Effects/**](./Effects/README.md) — Статусные эффекты (DoT, Buffs).
* [**Gifts/**](./Gifts/README.md) — Дары и магические школы.
* [**Triggers/**](./Triggers/README.md) — Система реактивных эффектов.
* [**Formulas/**](./Formulas/README.md) — Базовые формулы урона и шансов.
