# Status Effect Review

Status: idea for future combat-domain review.

The old RPG status document mixed implemented catalog effects with future
concepts. Do not treat it as a source of truth.

Future review should split:

- implemented effect catalog entries such as DOTs and control effects;
- runtime behavior in the combat ability/effect service;
- future control concepts such as fear;
- resistance channels for similar outcomes, for example stun, sleep, and fear
  limiting action through different defenses;
- possible tactical side effects, such as disrupting dodge, token gain, or
  combat rhythm.

This should be handled during a dedicated combat documentation pass against the
current effect catalog and resolver/runtime code.
