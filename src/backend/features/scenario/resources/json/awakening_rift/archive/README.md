# Awakening Rift Archive

This folder keeps inactive scenario material that should not be loaded as the
current `awakening_rift` flow.

`long_calibration_nodes/` contains the original long tutorial calibration chain:
bridge pools, reward routers, weapon/offhand/armor choices, and the old combat
handoff finale. The active scenario loader reads only `nodes/*.json`, so these
archived files remain available as writing examples without becoming live
scenario content.
