# FastAPI Cabinet Framework Docs

This directory contains documentation that belongs to the reusable
`fastapi_cabinet` framework, not to the TurnBasedMMORPG product docs.

Keep framework architecture, implementation workplans, public API notes, widget
contracts, and extraction notes here so this folder can move with
`src/fastapi_cabinet/` when the package is extracted.

Project-specific cabinet modules, game integrations, site dashboards, and
product/admin design notes should stay outside this directory.
