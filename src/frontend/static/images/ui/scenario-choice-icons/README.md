# Scenario Choice Icons

Runtime SVG icons for scenario action buttons.

Scenario JSON should keep semantic icon keys, for example:

```json
"icon": "warning"
```

Frontend code should map those keys to files in this folder. Do not point scenario JSON directly at reserve paths such as `tools/icon-reserve/...`.

The full raw Game-icons.net pack is kept in:

```text
tools/icon-reserve/game-icons-net/
```
